# Security and data disclosures

Please do **not** include private participant recordings, university access details, raw device metadata or tokens in public issues. For sensitive reports, open a GitHub private vulnerability report if the repository owner enables GitHub Security Advisories, or contact the maintainer privately using their publicly listed contact method.

The CLI operates locally and does not upload sensor data. Do not import or run research files from untrusted sources without checking their content. The software does not claim to perform legal or research-ethics assessment. Public-data publication is discussed in `docs/PUBLICATION_AND_ETHICS.md`.
