# Synthetic examples

`demo_gaze.png` and `demo_joy_weighted.png` were generated from entirely **synthetic input** with `python -m neuromarketing_heatmaps demo --output examples/generated`.

The two design blocks are fictitious. The plotted points are intentionally clustered to demonstrate how gaze sample density (unweighted) differs from a facial-expression-score-weighted density. They do not constitute research results or validated measurements of consumer interest or emotion.

The `generated/` folder is ignored by Git so running the demo will not change the published examples.
