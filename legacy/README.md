# Original 2023 research artefacts (historical only)

These files document the author's 2022-2023 University of Essex MSc final research project. They are preserved for research provenance, **not** as maintained entry points:

- `Data_Analysis.ipynb`: historical exploratory analysis and emotion-peak regression experiments.
- `Heat_map_Eye_Gaze.ipynb`: original gaze-density experiments.
- `Heatmap_with_mouse_scrolling.ipynb`: exploratory mouse-movement visualisation.
- `GUI_1.1_.py`: original procedural Tkinter interface.
- `scrolling-experiment/`: draft experimental browser extension source. Its original manifest was archived as non-loadable text because of expansive site access permissions. Do not install it as a browser extension without a separate security review.

The notebooks' saved outputs were cleared and personal absolute file paths generalised in the updated package. No original raw participant archive or study stimulus images are present. Legacy notebooks are not tested as production software, and any historical model result should be attributed to the original coursework rather than the refreshed analysis pipeline.

Use `python gui.py` or `python -m neuromarketing_heatmaps` at the repository root for supported functionality.
